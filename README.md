# Seatpax

Platform ticketing dan operasional penumpang bus antarkota multi-stop, dengan inventory kursi per segmen, layout armada dinamis, QR per penumpang, dan isolasi data antar-PO.

## Status project

Project saat ini berisi dokumentasi. Belum ada aplikasi, migration database, atau konfigurasi dependency. Stack dan roadmap dalam spesifikasi adalah rencana implementasi.
